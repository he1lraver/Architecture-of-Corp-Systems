# Первая практика по архитектурам корпоративных систем

Библиотечный каталог на Jakarta EE: добавление, изменение и удаление авторов и книг.

## Что находится в проекте

| Файл или папка | Назначение |
| --- | --- |
| `model/Author.java`, `model/Book.java` | JavaBeans, связанные с таблицами через JPA. У книги есть автор. |
| `service/LibraryService.java` | Сессионный EJB: получает и изменяет записи через `EntityManager`. |
| `service/LibraryException.java` | Ошибка ввода, при которой изменения в БД отменяются. |
| `web/AuthorServlet.java`, `web/BookServlet.java` | Принимают запросы из браузера и вызывают сервис. |
| `WEB-INF/authors.jsp`, `WEB-INF/books.jsp` | HTML-страницы с таблицами и формами. |
| `META-INF/persistence.xml` | Настройка JPA и имя источника данных на сервере. |
| `WEB-INF/web.xml` | Начальная страница приложения. |
| `database.sql` | Создание двух таблиц и начальные записи. |
| `pom.xml` | Настройки Maven: версия Java, библиотека Jakarta EE, сборка WAR. |

Java-файлы лежат в `src/main/java/edu/masters`, `persistence.xml` — в `src/main/resources`, страницы — в `src/main/webapp`.

Например, при сохранении автора форма отправляет POST в `AuthorServlet`. Он читает поля и вызывает `saveAuthor` у EJB. Сервис создаёт или изменяет JPA-сущность. Затем браузер возвращается к списку авторов. GET открывает страницу, POST изменяет данные.

В JSP тег `c:forEach` выводит строки таблицы, а `c:out` выводит текст, экранируя HTML. SQL и работа с БД находятся вне страниц.

## Запуск на Windows

Нужны JDK 21, Maven и WildFly 39. Драйвер реляционной СУБД H2 уже входит в WildFly. Используется файловая база: данные сохраняются после остановки сервера.

Команды ниже выполняются в обычной командной строке Windows. Java и Maven должны быть доступны через PATH. Укажите свой каталог установленного WildFly:

```bat
set WILDFLY_HOME=C:\wildfly-39.0.1.Final
```

1. Откройте командную строку в папке этой практики. Один раз создайте новую БД:

```bat
java -cp "%WILDFLY_HOME%\modules\system\layers\base\com\h2database\h2\main\*" org.h2.tools.RunScript -url "jdbc:h2:~/practice1" -user sa -script database.sql
```

База появится в домашней папке пользователя: `practice1.mv.db`. Скрипт предназначен для пустой базы; повторять его при каждом запуске не нужно.

2. Создайте пользователя консоли администратора стандартной командой WildFly. Выберите Management User и задайте логин и пароль:

```bat
"%WILDFLY_HOME%\bin\add-user.bat"
```

3. В отдельном окне запустите сервер:

```bat
"%WILDFLY_HOME%\bin\standalone.bat"
```

4. Откройте <http://localhost:9990> и войдите созданным пользователем. В консоли есть разделы **Deployments** (приложения), **Configuration** (настройки) и **Runtime** (состояние сервера).

5. В новом окне откройте административную командную консоль. Выполните в ней две команды, чтобы создать источник данных и проверить соединение:

```bat
"%WILDFLY_HOME%\bin\jboss-cli.bat" --connect
```

```text
data-source add --name=LibraryDS --jndi-name=java:/jdbc/LibraryDS --driver-name=h2 --connection-url="jdbc:h2:~/practice1" --user-name=sa
/subsystem=datasources/data-source=LibraryDS:test-connection-in-pool
```

Источник данных создаётся один раз. Его имя `java:/jdbc/LibraryDS` совпадает с именем в `persistence.xml`.

6. В папке практики соберите приложение:

```bat
mvn clean package
```

7. В браузерной консоли откройте **Deployments → Add → Upload Deployment**, выберите `target/library.war` и включите приложение (**Enabled**). Откройте <http://localhost:8080/library/>. Развёртывание выполняется через сервер, без IDE.

Для остановки выполните `shutdown` в административной командной консоли. При следующем запуске достаточно снова запустить WildFly: источник данных, приложение и файловая БД сохраняются.

## Связь с заданием

1. Сервер приложений — WildFly; управление через его консоль.
2. Реляционная СУБД — H2. В задании разрешена любая реляционная СУБД.
3. Две сущности: автор (имя, страна) и книга (название, год, автор); создание и заполнение таблиц — в `database.sql`.
4. Слой данных — JavaBeans с `@Entity`, полями и методами доступа.
5. Бизнес-слой — `LibraryService` с `@Stateless` и операциями чтения, добавления, изменения и удаления.
6. Представление — Servlet и JSP.
7. Страницы обращаются к EJB, EJB работает с БД через JPA. Для проверки добавьте автора, добавьте его книгу, измените записи, удалите книгу, затем автора.

Автор с книгами не удаляется: сначала нужно удалить книги или изменить их автора.
