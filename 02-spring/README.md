# Вторая лабораторная работа - Spring

Библиотека с авторами и книгами. Можно добавлять, изменять и удалять записи. У автора хранятся имя, страна и год рождения. У книги - название, год издания, цена, остаток и автор.

## Запуск

Нужны JDK 21 и Maven. Команды выполняются в папке этой работы, где находится pom.xml.

1. Собрать приложение и выполнить тесты:

```text
mvn clean verify
```

2. Один раз создать и заполнить новую базу H2:

```text
java -Dloader.main=org.h2.tools.RunScript -cp target/library.jar org.springframework.boot.loader.launch.PropertiesLauncher -url "jdbc:h2:file:./data/library;DB_CLOSE_ON_EXIT=FALSE" -user sa -password practice -script database.sql
```

H2 входит в собранный JAR. Команда запускает его SQL-утилиту с нашим скриптом. Повторять этот шаг при обычном запуске не нужно: начальные INSERT рассчитаны на новую базу.

3. Запустить приложение:

```text
java -jar target/library.jar
```

4. Дождаться сообщения Started LibraryApplication и открыть http://localhost:18280/.

Для остановки нажать Ctrl+C в окне сервера. При следующих запусках достаточно команды из шага 3. Данные находятся в data/library.mv.db и сохраняются после перезапуска. Папку data копируют только после остановки приложения. Если порт занят, можно запустить с параметром --server.port=18281 и открыть соответствующий адрес.

WildFly для этой работы не требуется: Spring Boot запускает встроенный веб-сервер. Все команды сборки и запуска выполняются из одной папки. Тесты используют отдельную базу в памяти и не меняют рабочие данные.

## Устройство проекта

- src/main/java/edu/masters/domain - JavaBeans Author и Book с аннотациями Hibernate/JPA и проверки полей Rules.
- src/main/java/edu/masters/spring/LibraryService.java - Spring Bean с @Service и @Transactional. Чтение и изменение данных через EntityManager.
- src/main/java/edu/masters/spring/LibraryController.java - Spring MVC: получает формы, вызывает сервис и выбирает шаблон.
- src/main/resources/templates - HTML-шаблоны Thymeleaf. Значения модели выводятся с экранированием.
- src/main/resources/static/style.css - оформление страницы.
- src/main/resources/application.properties - H2, Hibernate и порт сервера.
- database.sql - создание таблиц и начальные записи.
- src/test - проверки Spring MVC и операций с данными.
- pom.xml - зависимости и сборка Maven.

Запрос проходит через контроллер к сервису. Сервис работает с сущностями в транзакции, Hibernate выполняет SQL, а контроллер передаёт результат HTML-шаблону. Три слоя находятся в одном приложении.

## Соответствие заданию

1. Предметная область и SQL: две связанные сущности Author и Book, несколько свойств у каждой; database.sql создаёт и заполняет таблицы.
2. Данные: классы JavaBeans имеют конструктор без параметров и методы доступа, @Entity и @Table. Hibernate подключён через Spring Data JPA; схема проверяется настройкой ddl-auto=validate.
3. Бизнес-слой: LibraryService зарегистрирован как Spring Bean. Методы выполняют чтение, добавление, изменение и удаление в транзакциях.
4. Представление: LibraryController использует Spring MVC, шаблон library.html показывает формы авторов и книг.
5. Совместная работа: после запуска страницы обращаются к сервису и файловой БД; предусмотрены проверки CRUD и ошибок ввода.

## Проверка через браузер

Добавить автора, затем его книгу. Изменить имя автора, название и цену книги, сохранить и обновить страницу. Перезапустить приложение и проверить сохранённые изменения. Удалить книгу, затем автора.

Автор с книгами не удаляется: сначала нужно удалить книги или назначить им другого автора. Начальные записи подчиняются тому же правилу. Цена неотрицательная, максимум два знака после точки; остаток неотрицательный, включая ноль; год от 1 до следующего календарного года. Неверные значения отклоняются на сервере.
